Frota Registrar visita

1. Carregar dados

Se o carro já tem etiqueta, leia os dados atuais para só atualizar o que mudou. Carro que já está no sistema é carregado ao digitar a placa. Carro novo: pule para o passo 2.

2. Dados da visita

O PDF fica guardado no sistema com a visita. Se ele tiver texto, os campos abaixo são preenchidos com placa, cliente, telefone, km e serviços.
Cole a placa, o km e os itens da ordem de serviço; os serviços reconhecidos são marcados como feitos hoje. O texto do PDF aparece aqui.

Marque os serviços feitos nesta visita para preencher com o km e a data de hoje. Os outros mantêm o último registro.

Salvar não depende da etiqueta: a visita, o cliente e o PDF vão para a tela de frota. A etiqueta pode ser gravada agora, no passo 3, ou depois pela tela de frota.

3. Gravar etiqueta (opcional)

No computador? Leia este QR code com o celular (Chrome no Android, logado na área da oficina) para abrir esta placa com os dados salvos e gravar a etiqueta por NFC.

QR code da página do cliente (alternativa à NFC)
A gravação por NFC funciona no Chrome para Android, com a página publicada em https. Em outros aparelhos, copie o link e grave com um app de NFC (por exemplo, NFC Tools), ou imprima o QR code.
