Área da oficina

1. Carregar etiqueta

Se o carro já tem etiqueta, leia os dados atuais para só atualizar o que mudou. Etiqueta nova: pule para o passo 2.

2. Dados da visita

Cole a placa, o km e os itens da ordem de serviço; os serviços reconhecidos são marcados como feitos hoje.

Marque os serviços feitos nesta visita para preencher com o km e a data de hoje. Os outros mantêm o último registro.

3. Gravar

Ver como o cliente
QR code do mesmo link (alternativa à NFC)
A gravação por NFC funciona no Chrome para Android, com a página publicada em https. Em outros aparelhos, copie o link e grave com um app de NFC (por exemplo, NFC Tools), ou imprima o QR code.
